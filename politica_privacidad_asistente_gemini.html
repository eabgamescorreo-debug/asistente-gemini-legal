Política de privacidad de Asistente Gemini

Última actualización: 26 de octubre de 2026

Responsable: Familia Albert. Contacto: familiaalbertcorreo@gmail.com.

1. Qué hace la skill

Asistente Gemini es una skill personalizada de Alexa que permite formular preguntas por voz y recibir respuestas generadas mediante la API de Gemini de Google.

2. Datos tratados

Alexa procesa la interacción de voz y envía a la skill el texto reconocido y los datos técnicos necesarios para atender la solicitud. La skill envía a Google, a través de la API de Gemini, el texto de la pregunta, las instrucciones del asistente y el historial reciente de la conversación activa para generar una respuesta. Por ello, no incluyas contraseñas, datos bancarios, información sanitaria sensible ni otros datos confidenciales en las preguntas.

3. Finalidad y destinatarios

Los datos se utilizan para responder a las preguntas y conservar el contexto durante la sesión activa de Alexa. El texto de la pregunta y el contexto se transmiten a Google para usar Gemini. El funcionamiento también depende de la infraestructura de Amazon/AWS que aloja la skill. Amazon y Google pueden tratar datos conforme a sus propias condiciones y políticas.

Información de Google sobre el tratamiento de datos con la API de Gemini: Condiciones adicionales de la API de Gemini y Política de privacidad de Google.

4. Conservación

Según el código actual de la skill, el historial de conversación se mantiene en los atributos de la sesión activa y no se guarda intencionadamente en una base de datos propia para recuperarlo en futuras sesiones. Los proveedores técnicos pueden conservar datos o registros durante los plazos establecidos en sus políticas y condiciones. Los registros técnicos de errores deben configurarse para no incluir claves ni contenido innecesario.

5. Permisos y vinculación de cuentas

La skill no necesita vincular una cuenta de usuario ni solicitar permisos para acceder al nombre, correo, teléfono, ubicación o listas de Alexa para realizar su función básica.

6. Seguridad

El responsable debe proteger la clave de API, no publicarla en páginas o repositorios abiertos y renovarla si se expone. No se debe utilizar la skill para transmitir información personal o confidencial.

7. Derechos y contacto

Para consultas sobre privacidad o para ejercer los derechos que correspondan conforme a la normativa aplicable, contacta con familiaalbertcorreo@gmail.com.
